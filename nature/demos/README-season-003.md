# 青池四季 003｜分層森林與岸雪微地形

版本：003（衍生自 002，原始 001/002 **不修改**）
日期：2026-11-04（臺灣）

## 本輪已實作
- 遠岸樹林改為兩層、樹高/寬/位置/葉色帶固定種子的變化，含闊葉與針葉輪廓。以程式化樹冠取代規則三角尖頂背景。
- 秋季：闊葉樹群以不同的赭橙/褐紅比例變色；保留一部分針葉深綠，不把整個畫面一起染紅。
- 冬季：在 `shoreHeight()` 計算加上隨植被季節變換的不規則雪層高度，並在坡面用雜訊調整積雪遮罩；這是 **shader 的幾何/材質視覺候選**，沒有修改遊戲碰撞或增加可踩踏冰面。
- 水面：保留水體波浪法線、Fresnel、樹影光線反射。樹林季節色可透過 `environment()` 隨 `reflectScene()` 影響倒影。
- 同鏡位 A/B：提供「002 舊效果／003 新效果」開關 `uDetail`；切換時相機、風、水色與季節數值不重置。
- 限制每個樹冠的高成本雜訊評估，對遠離樹冠的像素做剔除，仍待 GPU 效能驗證。

## 待測：不可誤稱已通過
- Chromium 在本環境三種後端（SwiftShader、EGL、SwiftShader-WebGL）均無法取得 WebGL2 context。
- **GLSL 編譯、實際 WebGL2 畫面、原/新版本目視比較、FPS、手機/Android/iOS、森林遮擋與倒影的最終品質均未通過驗收**。
- 並非現地測繪的美瑛白金青池重建，亦未移植 Leonxlnx/open-water 的完整四層 FFT。
- 不含真正的冰面碰撞、積雪物理或降雪粒子。

## 本機驗收步驟
1. 下載 `blue-pond-seasons-003.html` 並在支援 WebGL2 的 Chrome/Edge 開啟。
2. 等待左下角顯示 WebGL2 運作中，確認沒有 Shader 錯誤。
3. 同一鏡位依序切換秋季、冬季；在相同設定下開/關「比較：002 舊效果」。
4. 記錄瀏覽器、GPU、解析度、平均/最低 FPS 與相同鏡位截圖；如編譯或效能失敗，保留 002。
5. **任何實際遊戲移植仍必須另外建立獨立副本，不能覆蓋已部署地圖。**
