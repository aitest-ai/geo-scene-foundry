# 青池 009｜保留湖水畫質的效能優化

009 以 GitHub 的 008 母版製作獨立候選程式；沒有修改 001～008 或既有地圖。

## 新增功能

- 保守的枯立木區域快速排除：光線完全不會穿過枯木林時，省去逐棵樹幹／枝條相交。
- 對岸地形的粗搜尋，在 t > tWater + stepT 後停止，保留足夠步長供原本的細分搜尋。
- 活躍落水漣漪事件集中儲存，uImpactCount 避免重複計算不存在的事件。
- 季節粒子完全透明的區域先丟棄，避免無效的遮擋計算。
- 使用者能切換 008／009 運算，固定鏡位與時間跑 008→009→009→008 的同步 A/B，匯出中位數、p95 與 JSON。
- 008 的水色、反射及 Fresnel 核心 shadeWater 函式逐字保留。

## 驗證

本機 Node 9 項測試通過，OpenGL ES 3.2 Mesa llvmpipe 主場景及粒子 Shader 編譯、連結通過；所記錄的夏、秋、冬、粒子與不同視角，008 和 009 畫面 RGB 差異為 0。當中多數軟體渲染樣本幀時間縮短，但存在冬季粒子＋漣漪反而較慢的情況。

請讀 nature/benchmarks/blue-pond-009-llvmpipe.json。數字是 glFinish 同步完成的耗時，不是純 GPU timestamp 或實體硬體 FPS；需在使用者 Chrome/Edge/手機再測。
