# Blue Pond Nature 004 — 季節落物 GPU 實驗

日期：2026-11-04。以 `blue-pond-seasons-003.html` 為基底**新增 004**。原版 001／002／003、洞爺湖及鄭成功遊戲與既有 Vercel 部署均不更動。

## 新功能
- 獨立 WebGL2 GPU 粒子 pass：`particleVert` / `particleFrag` 以 `gl_VertexID` 生成 320 個固定種子的候選粒子，無外部模型／貼圖。
- 春：淡粉花瓣；夏：無落物；秋：赭黃落葉；冬：白色細雪。可調強度 0～1、由風力影響漂移。
- 季節轉換、粒子開關與暫停動畫；保留原 003 水面、森林、岸雪與舊效果 A/B。
- 粒子 Shader 編譯失敗時應回退到 003 的湖面渲染，顯示錯誤資訊，不因可選特效讓整個水景失效。
- 手機窄螢幕的控制面板可以捲動。

## 技術界線
這是視覺動態**原型**。粒子尚無與岸樹、地面、水面的深度遮擋或碰撞；沒有堆雪、落葉累積、物理水波受粒子撞擊、真實天候模擬、環境音效或完整 Open Water FFT。不能稱為青池現地測量結果。

## 驗證
- JS `node --check` 通過；獨立測試中的六項程式／完整性檢查通過。
- 先前 003 SHA-256 維持 `af19b7fffeb1071895fe1a2ecc5131c68d05152827103651d1cb59a89eb5ac5b`。
- 這個執行環境 Chromium 的 `file://` 導航受到管理限制，`set_content()` 下 WebGL2 context 不可用。**沒有完成實際 shader GPU 編譯、品質截圖、FPS 或 Android/iOS 驗收。**
- 完整 Q/A 記錄見 `blue-pond-004-qa.json`。

## 驗收指引
1. 於受支援 WebGL2 的桌機開啟 004，確認原水面與樹林仍正常。
2. 同鏡位依序選春／夏／秋／冬，檢查花瓣、夏季粒子消失、秋葉、冬雪。
3. 切換「004 季節粒子」開關與強度 0、0.65、1，並使用暫停動畫作同鏡位比較。
4. 用手機直橫式測 FPS、p95 幀時間；檢查粒子不會穿過近景樹木（尚未支援遮擋，應列為待修問題）。
5. 如任何目標裝置不通過，回退 003。正式地圖不自動更新。
