# 青池自然湖岸 006｜修復灰白山牆、緩坡與森林深度

日期：2026-11-04。從 **005 Fix1** 複製，另存 006。原本 001～005 與洞爺湖等正式地圖不修改。

## 來自使用者畫面的診斷
冬季對岸是高且平整的灰白色帶狀地形，幾乎擋住整片森林，後方還有規律三角形樹。根因：
`shoreHeight` 隨遠岸距離 `sd` 線性成長（`sd*.21`），且 `render()` 的地形優先遮擋後方森林；冬雪材質顏色偏一整面灰白。

## 006 修改
- `shoreHeight()` 以有界的 `smoothstep` 岸坡代替無上限線性高度，新增土壤紋理及冬雪斑塊。
- 遠方兩層柔和、不規則的低丘；岸邊補上有深度的林冠層。
- 修正近岸地形與樹林的前後景關係，地形交點改用粗搜尋後細分定位。
- 主場景和獨立粒子 Shader **都**使用相同的 006 岸坡公式，避免落葉雪花與地面不一致。
- `uLandscape=1` 為 006，`uLandscape=0` 為 005 舊樣式；相機、風力、季節與時間皆保持一致。
- 水面、枯立木、粒子與接觸漣漪功能保留，不重作水面。

## 測試
- Node.js 006 回歸測試：6/6 PASS。
- EGL / ANGLE OpenGL ES 3.0：主場景及粒子 Shader 四個階段編譯、兩組程式連結全部 PASS。
- 540×304 EGL 離屏冬季同鏡位 A/B 截圖已生成。視覺上 005 灰白高牆消失，改為低坡、森林與遠丘。
- 小樣圖診斷區域（畫面高 40%-58%）的「淺灰、低彩度」像素比例由約 42.5% 降至 3.8%；僅是輔助目視的自定義影像指標，並非擬真度評分。
